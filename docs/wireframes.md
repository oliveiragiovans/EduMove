# 🎨 EduMove - Wireframes

## Overview

This document presents the initial wireframes for the EduMove application. The purpose is to define the navigation flow and the main user interfaces before implementation.

---

# Navigation Flow

```text
Login
   │
   ▼
Dashboard
   │
   ├── Classes
   │      └── Students
   │               └── Assessments
   │
   ├── Reports
   │
   └── Settings
```
